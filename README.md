Auto Color Top Bar is a GNOME Shell extension that dynamically changes the top bar color based on the current desktop wallpaper or a manually selected color.

It supports two modes:

• Auto mode: extracts a dominant color from the active wallpaper using GNOME background settings.

• Manual mode: allows the user to pick a custom color using a built-in color selector.

The extension automatically updates the top bar when the wallpaper or settings change, providing a seamless and adaptive desktop experience.

Features:
• Automatic color extraction from GNOME wallpaper

• Auto Color Panel and Transparency, to handling the values ​​of the dash and the primary background color.

• Manual color picker

• And it allows you to choose the opacity.

• Live updates when switching wallpapers

• Lightweight and simple design

• No external dependencies

Designed for GNOME Shell users who want a clean, adaptive and visually consistent top bar.

Installation:
 
1. Extract the ZIP file to your GNOME Shell extensions directory:

   ~/.local/share/gnome-shell/extensions/

2. Open a terminal and run:

   glib-compile-schemas ~/.local/share/gnome-shell/extensions/AutoColor-top-Bar@baitsart.github.com/schemas

   gnome-extensions enable AutoColor-top-Bar@baitsart.github.com

3. Log out and log back in (or restart GNOME Shell) if the extension does not appear immediately.
